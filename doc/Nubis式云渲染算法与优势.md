# Nubis 式云渲染算法（Vapor）与优势

> 参考资料：Guerilla Games《Nubis》云渲染系统
> 模块：`Vapor`（Runtime 渲染）
> 日期：2026-09-02

---

## 1. 算法概述

Vapor 基于 **Nubis**（Guerilla Games《地平线》系列的体积云方案），本质是一套**实时体积云光线步进**系统，由两道 compute pass 构成：

1. **烘焙 pass**（`CloudBakeCS.usf`）——半分辨率、多帧分片预计算"光照缓存"。
2. **主积分 pass**（`CloudMarchCS.usf`）——逐像素光线步进，读取缓存做阴影/透射样。

体积规模：**512×512×64 体素，每体素 8 米**，即世界空间约 **4×4×0.5 km**。所有距离以**米**为单位（UE 默认厘米，shader 内做 `CM_TO_M` 换算）。

## 2. 核心设计

### 2.1 双场分离：轮廓（SDF）与密度细节（scale）解耦

不同于把"形状 + 细节"烘焙进**单一密度场**的常规做法，Nubis 用**两个独立网格**：

- **形状**：来自 3D **有符号距离场**（`SignedDistanceField`），通过 `SampleCloudDistance()` → `DistanceToDimensionalProfile()` 得到云的三维轮廓。
- **密度细节**：来自另一张 **density scale** 纹理（`DensityTexture`），二者独立采样后相乘得到最终密度。

> 好处：轮廓决定"云长什么样"，密度决定"云多密多透"。两者解耦后，可复用同一体积调密度而不改变形状。

### 2.2 时间交错的"渐进式光照烘焙"

烘焙 pass 预烘焙一张**持久化半分辨率 3D 缓存**（256³），每格存 `(阳光光路密度, 环境遮蔽)` 两个值。

关键代码：

```hlsl
const uint3 OutputId = (DispatchThreadId << 1u) + uint3(FrameIndex & 1u, (FrameIndex >> 1u) & 1u, (FrameIndex >> 2u) & 1u);
```

用帧号的三位比特，**每帧只更新 8 个子格中的 1 个**，整张缓存每 8 帧完整刷新一次。主 pass 直接查缓存做透射/阴影，**不再对每像素实时做光路追踪**。

### 2.3 SDF 加速的自适应步长

体积纹理存有符号距离场，用它做**动态步长**：

```hlsl
const float WStepSize = max(WCloudDistance, WAdaptiveStepSize);
```

- 远离云表面 → 大步长快速跳过空区域；
- 靠近云表面 → 步长自动收小，避免穿过薄云却采样不到。

SDF 编码范围**非对称**（`-32 到 +512` 映射到 G16），用于让轮廓/呼吸过渡更平滑。

### 2.4 环境光遮蔽用"锥形追踪"烘焙进体积

烘焙阶段对每个体素做 **6 个方向的锥形追踪**（上半球权重 0.5，四周 0.25 各四个），把遮蔽值写进缓存，得到体积级 AO。

### 2.5 噪声上采样：低精度体积 + 实时细节

靠世界空间噪声"提分辨率"：

```hlsl
const float3 SweptUVW = WSampleLocation - Cloud.WindSpeed * View.GameTime;
```

- 噪声随**风速在时间内平移**（云随时间动起来）；
- 两种噪声按轮廓渐变混合：**丝状（wispy，低压区域）+ 蓬松（billowy，高压区域）**，对应"稀薄处拉丝、浓密处起泡"的细节。

一行代码同时实现**动画 + 高频细节**，无需真正提高体积分辨率。

### 2.6 三类散射独立开关

**直接 / 多重 / 环境散射**为三个可独立开关的通道，方便调参与性能分档。

## 3. 算法优势

### 3.1 性能优势（最核心）

| 设计 | 带来的性能收益 |
|---|---|
| 时间交错渐进烘焙 | 把昂贵的"往太阳方向光路追踪"**摊薄到 8 帧**，而非每帧全算 |
| SDF 自适应步长 | 空区域大步跳过，**显著减少采样次数**，比固定步长高效得多 |
| 烘焙缓存查询阴影 | 主 pass **零开销**获取透射/阴影，无需实时二次 ray marching |
| 锥形 AO 烘焙进体积 | AO 成本被**前置分摊**，逐像素只做一次查询 |

### 3.2 质量优势

- **双场分离**让"形状"与"密度"独立可控，艺术调参更灵活：可保持形状不变，单独调浓度/透光。
- **噪声上采样**用极低的体积分辨率换来近似高分辨率的高频细节，兼顾细节与显存/带宽占用。
- **三类散射独立**支持按需要组合，在写实与性能之间灵活取舍。

### 3.3 工程优势

- 所有光照信息（阴影/AO/透射）被**预计算并缓存**，主渲染路径变得**简单且便宜**——这是 Nubis 最精髓的"每帧便宜、多帧分摊"设计哲学。
- 纯 compute shader + SceneViewExtension 注入，**不依赖引擎网格/材质系统**，易于作为独立插件集成。
