# Vapor 与高度雾 / 半透明混合的问题

> 状态：待解决（Work In Progress）
> 模块：`Vapor`（Runtime 渲染）
> 日期：2026-09-02

---

## 1. 问题摘要

Vapor 云渲染（基于 Nubis 方案）在与 **高度雾（ExponentialHeightFog）** 和 **半透明物体（Translucency）** **同场景共存**时，混合结果不符合物理预期：

| 组合 | 结果 | 说明 |
|---|---|---|
| 云 遮挡 云后面的半透明物体 | ✅ 基本正确 | 半透明已合成进 SceneColor，云做前景压暗 |
| 云 位于 前面的半透明物体之后 | ❌ 错误 | 云注入在后处理阶段，永远叠在半透明之上 |
| 高度雾 衰减 云自身 | ❌ 缺失 | 云的散射光不含雾衰减项，远云会突兀 |
| 云 遮挡 雾化后的背景 | ⚠️ 部分正确 | 背景混得对，但云自身无雾，前后不一致 |

---

## 2. 背景：渲染管线顺序（UE5）

Vapor 通过 `PrePostProcessPass_RenderThread` 注入渲染，该注入点在管线中**非常靠后**：

```
BasePass（不透明）
→ Lights
→ SingleLayerWater
→ SkyAtmosphere
→ Exponential Height Fog（高度雾，作用于不透明物体）
→ Volumetric Cloud（UE 自带的体积云）
→ Translucency（半透明，标准 pass 合成进 SceneColor）
→ PostProcessing  ←──── Vapor 的 PrePostProcessPass 在这里
→ Bloom / Tonemapping / TAA
```

Vapor 的 `PrePostProcessPass_RenderThread` 读取的 `SceneColor` **已经包含**：不透明场景 + 高度雾 + 半透明合成后的完整画面。随后做云的光线步进：

```hlsl
最终像素 = SceneColor * (1 - 云吸收) + 云的散射光
```

---

## 3. 根因分析

### 3.1 高度雾：云不吃雾

高度雾在 Vapor **之前**已应用到场景背景，因此合成公式变成：

```
最终像素 = 雾化后的背景 * (1 - 云吸收) + 云的散射光(未雾化)
```

`CloudMarchCS.usf` 里的 `IntegrateCloudSample` 只包含 **太阳散射 / 多重散射 / 环境散射**，**没有任何 `exp(-fogDistance)` 雾衰减项**：

- 背景部分正确被雾洗白/衰减（因为它在 Vapor 之前已雾化）；
- 云自身的发光部分完全没有被雾衰减。

**后果**：远处的云本应被高度雾变得朦胧、低对比、融入雾色，但 Vapor 的云会以**全亮、全清晰**的方式直接盖在雾化背景上。雾越浓、云越远，不匹配越明显（云像"从雾里硬顶出来"一样突兀）。

> 对比 UE 自带 Volumetric Cloud：把高度雾采样**集成到云的步进内部**，云能随雾衰减。Vapor 目前未实现。

### 3.2 半透明：后向对、前向错

- **半透明在云后面** ✅：半透明合进 `ViewColor`（背景），云用 `ViewColor * (1 - Absorption)` 压暗，云在前面正确遮挡。
- **半透明在云前面** ❌：
  - 半透明在 Vapor **之前**已渲染进 SceneColor；
  - Vapor 判断步进停止用的 `WDepth` 来自 **`SceneDepth`（只有不透明深度）**，半透明物体**不写深度**；
  - 所以云不会被前面的半透明物体"截断"，会一路步进并把云完整地叠在半透明物体之上 → 云错误地盖住了它前面本该遮挡云的玻璃/粒子/水。

另外，云的输出是 `float4(FinalColor, 1)` —— **不透明合成，alpha 恒为 1**，没有 alpha 通道，对半透明物体及后续依赖 alpha 的处理都不友好。

---

## 4. 影响

- 远距离云 + 浓雾 → 云突兀、不融入环境，视觉穿帮。
- 云前方的半透明物体被云错误遮挡。
- 云不写入深度，后续后处理（DOF、屏幕空间 AO 等）忽略云。

---

## 5. 解决方案方向

1. **让云集成高度雾**：在 `TraceVolume` / `IntegrateCloudSample` 中把高度雾的透射率加进云的 in-scattering，使云随距离被雾衰减。
2. **调整注入时机**：让云在**半透明之前**渲染（或输出 alpha），避免永远叠在半透明之上。
3. **云输出 alpha**：改用带 alpha 的合成方式，让半透明物体能正确参与混合。
